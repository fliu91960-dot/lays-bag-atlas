# 乐事薯片袋图鉴

在线浏览：https://fliu91960-dot.github.io/lays-bag-atlas/

当前收录 207 条产品记录，覆盖中国大陆、中国台湾和中国香港。包含不同市场、系列及包装形态，不代表 207 种独立口味。已有141张包装图，其余卡片显示“图片待补”。

公共图鉴数据保存在 [catalogue.json](catalogue.json)，与网页同步更新。该文件是公开数据文件；个人收藏保存在各自浏览器，目前尚未接入云端用户数据库。

年份区分包装年份和口味首见年份；参考表待核年份保留标记。
