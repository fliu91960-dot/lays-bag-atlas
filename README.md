# 乐事薯片袋图鉴

[打开在线图鉴](https://fliu91960-dot.github.io/lays-bag-atlas/)

共 211 款包装，其中 200 款有展示图。可按口味、系列或批次搜索，按地区、包装年份、类型和净含量筛选。个人收藏保存在访问者的浏览器。

## 仓库内容

| 位置 | 用途 |
| --- | --- |
| [catalogue.json](catalogue.json) | 全部在架单品记录，含包装年份、口味首见时间和资料来源 |
| [assets/](assets/) | 在架包装的展示图片及缺图占位图 |
| index.html、styles.css、icon.png | 网页入口、布局和站点图标 |
| app.js、core.js、repository.js | 浏览交互、图鉴规则和浏览器收藏存储 |
| .nojekyll | 供 GitHub Pages 直接发布静态文件 |

网站从 main 分支根目录发布。资料和图片在开发项目中维护后一起导出至本仓库。
